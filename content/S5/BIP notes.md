
# Réunion début

## Sujet de projet

Build a mobile application that empowers users to take care of their emotional well-being. Focus on simplicity

Must have :
- 2-3 screens, Material Design, Responsive Layout
- Authentification with email or oauth (google/github), firebase auth, nodejs, google oauth...
- Database for user data (CRUD), user-specific data, firestore, postgresql, musql
- State management (setState or BloC pattern)

Nice to have :
- mood visualization
- offline support
- dark mode
- push notifications

Goal: MVP by Wednesday

Friday is for polishing the product (debugging, UI tweaks and demo prep)
