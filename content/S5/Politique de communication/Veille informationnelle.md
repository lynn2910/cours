# Définition

« Demeurer informé(e) des nouvelles publications et des nouveaux développements dans un domaine. »

## Trois principales sortes de veille

### Technologique

Surveillance :
- des développements techniques ou scientifiques ;
- des performances de produits ;
- des résultats de recherche ;
- des applications innovantes.

### Économique

Surveillance :
- commerciale ;
- concurrentielle ;
- du marché.

### Règlementaire

Surveillance :
- normative ;
- des brevets ;
- juridique.

## Deux méthodes

### Manuelle (= pull)

Se rendre sur différents sites pour trouver de l'information.

### Automatisée (=push)

Programme avec une application ou un logiciel de réception de l'information.

## Deux sortes de sources

### Sources plutôt généralistes

- presse spécialisée (*Numerama, 01.net, Journal du Net, rubrique Pixels dans le Monde,* etc.) ;
- certaines chaines Youtube, certains comptes TikTok/Instagram, ou LinkedIn, etc.

### Sources scientifiques

- Articles ou thèses spécialisées.

> [!tip] Le cours suit surtout les sources scientifiques

# Stratégie pour réaliser une veille informationnelle

## Cibler informations et sources

Première étape essentielle : elle a un impact sur toutes les actions suivantes.

Il faut savoir ce dont on a besoin pour mettre en place sa stratégie.

Grâce à des connaissances et à des premières recherches :
- déterminer une liste de sujets utiles pour mieux cerner les informations recherchées ;
- transposer cette liste en mots-clés.

Cibler :
- les informations recherchées ;
- les mots-clés à utiliser ;
- les canaux d'informations utiles.

## Créer des alertes

Mettre en place des alertes lors de la parution sur le web de contenus potentiellement intéressants.

Le plus simplet à mettre en place : **Flux RSS** pour syndiquer un site web sélectionné.

Nouveauté répondant aux mots-clés choisis :
- affichage du titre ;
- et rapide description.

## Veiller de deux façons

### Veille cible

- définir les sujets à surveiller ;
- identifier les sources pertinentes ;
- les mettre sous surveillance par les biais d'outils.

### Veille radar

Définir des mots-clés sur le sujet de recherche pour faire émerger tous types d'informations, provenant de tous types de source.

On peut aussi créer des alertes par mots-clés.

> [!example] Exemple :Google Alertes

Cela permet d'analyser l'information.

## S'organiser

L'objectif est de **ne pas être submergé** par les informations.

1. **Classer**, organiser des dossiers **par thématique** ;
2. fixer des **horaires** de veille ;
3. lire rapidement ses flux : repérer les plus pertinents pour les marquer et les approfondir après ;
4. hiérarchiser les dossiers et flux par priorité.

Le mot d'ordre est : Trier, traiter et analyser les informations.

L'objectif est de :
- ne garder que les informations utiles ;
- synthétiser toutes les informations récupérées pour les rendre exploitables et pour les partager ;
- les organiser.

# Recherches scientifiques et techniques sur Internet

## Fonctionnalités de recherche avancée

### Opérateurs booléens

| ET                                                                                 | OU                                         | SAUF                                                | « »                             | ( )                                                                                                             |
| ---------------------------------------------------------------------------------- | ------------------------------------------ | --------------------------------------------------- | ------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Chercher deux éléments ensemble pour limiter les résultats.<br><br>*IA ET langage* | Chercher deux mots ensemble ou séparément. | Ignorer un mot. <br>*apprentissage SAUF motivation* | Utiliser une expression exacte. | Appliquer des opérateurs à toute la recherche ou à certaines parties.<br><br>*travail ET (domicile OU distance* |

> [!tip] Il est conseillé de mettre les opérateurs en capitale et de ne pas utiliser de capitale dans les termes.
> Les moteurs de recherches ne peuvent pas différencier les opérateurs des termes autrement.

## Sites utiles pour les recherches universitaires

- Catalogue des **BU** de l'UMLP accessible depuis l'ENT ;
	- se connecter pour faire une recherche avancée ;
	- sélectionner un document au titre jugé intéressant ;
	- lire le résumé de la fiche descriptive : pertinent d'ouvrir le document.


> [!tip] Possible de s'abonner aux flux RSS de la BU
> Catégories disponibles :
> - **HAL (Hyper articles en ligne) :** dépôt de diffusion d'articles et de thèses scientifiques ;
> - **ScienceDirect d'Elsevier :** Base de donnée multidisciplinaire ; Accès à des revues en texte intégral entre autre dans le domaine de l'information ;
> - **Web of Science (WOS) :** base de donnée bibliographique multidisciplinaire ; Accès à de nombreuses références d'articles scientifiques, d'actes de conférences et de livres - texte intégral souvent disponible ;
> - **BASE :** Moteur de recherche consacré à la littérature scientifique : sources sélectionnées par des professionnels, y compris dans le *Dark Web* : Documents en libre accès ;
> - **FreeFullPDF :** Moteur de recherche spécialisé dans les publications scientifiques en libre accès ;
> - **Google Scholar :** La quantité mais pas toujours la qualité : tous les documents ayant plus ou moins l'apparence d'un article scientifique mais sans garantie de fiabilité

> [!danger] Site illégal : Sci-hub
> Site web pirate fournissant un accès libre à des articles scientifiques obtenus par **web scrapping** en contournant les **paywalls** classiques des éditeurs académiques.
> 
> Un VPN est <u><b>NECESSAIRE</b></u> pour accéder à *Sci-hub* en France.

# Outils pour automatiser les recherches

## Alertes

### Avoir bien défini ses mots-clés

Réception par mail ou par flux RSS de liens adaptés à ses besoins.

## Flux RSS

> [!example] RSS = Really Simple Syndication

Permet de :
- recevoir les informations mises à jour en temps réel sur des sites sélectionnés ;
- ensemble des informations potentiellement utiles regroupé dans une seule fenêtre ;
- gain de temps, à condition :
	- d'avoir bien défini ses mots-clés ;
	- de le consulter régulièrement sous peine que ce soit ingérable.

Possible de suivre les flux depuis son navigateur :
- Awesome RSS pour Firefox ;
- Feeder pour Chrome.

Principaux lecteurs de flux RSS proposant des offres gratuites :
- Feedly pour sa facilité ;
- Inoreader pour son adaptabilité ;
- Flipboard pour se constituer une revue de presse ;
- Netvibes pour concevoir des tableaux de bord personnalisés de suivi de l'actualité
- etc.
